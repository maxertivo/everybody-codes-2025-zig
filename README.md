This is a Zig implementation of the 2025 edition of the Everybody Codes challenges (https://everybody.codes/event/2025/quests). This code only depends on the Zig standard library. 

This was written to be compatible with Zig version 0.16.0. As Zig is still changing with each release, this may not work using other versions.

To compile and run in debug mode, go into the root folder and run "zig build run".
To compile a faster version with safety checks, go into the root folder and run "zig build --release=safe". The executable will be in the "zig-out" folder.
